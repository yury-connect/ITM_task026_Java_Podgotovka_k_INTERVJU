
Этот SQL-запрос **находит дублирующиеся email-адреса** в таблице `users`.

```sql
SELECT email, COUNT(*) AS dup_count
FROM users
GROUP BY email
HAVING COUNT(*) > 1;

-- Пример результата:
-- email    | dup_count
-- test@mail.com    | 3
-- a@b.com    | 2
```

### Пошагово:

|Часть запроса|Что делает|
|---|---|
|`SELECT email, COUNT(*) AS dup_count`|Выбирает email и считает количество строк для каждого email|
|`FROM users`|Из таблицы users|
|`GROUP BY email`|Группирует строки по email (уникальные email → группы)|
|`HAVING COUNT(*) > 1`|Оставляет только те группы, где количество > 1 (т.е. дубликаты)|

### Результат:
```text
| email         | dup_count |
| ------------- | --------- |
| test@mail.com | 3         |
| a@b.com       | 2         |
```
Это означает:
- `test@mail.com` встречается 3 раза → 2 дубликата
- `a@b.com` встречается 2 раза → 1 дубликат
