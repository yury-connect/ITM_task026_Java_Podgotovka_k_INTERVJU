
**Этот запрос находит дублирующиеся email-адреса и нумерует каждое вхождение в порядке создания (created_at).**
```sql
WITH numbered AS (
    SELECT
    email,
    created_at,
    ROW_NUMBER() OVER (PARTITION BY email ORDER BY created_at) AS rn
    FROM users
)
SELECT email, created_at, rn
FROM numbered
WHERE email IN (
    SELECT email
    FROM users
    GROUP BY email
    HAVING COUNT(*) > 1
)
ORDER BY email, rn;

-- Пример результата:
-- email         | created_at           | rn
-- test@mail.com | 2024-01-10 10:00:00  | 1
-- test@mail.com | 2024-02-15 12:00:00  | 2
-- test@mail.com | 2024-03-20 14:00:00  | 3
-- a@b.com       | 2024-01-05 09:00:00  | 1
-- a@b.com       | 2024-01-20 11:00:00  | 2
```

### Пошаговый разбор:

|Часть|Что делает|
|---|---|
|**WITH numbered AS (...)**|Создаёт временный CTE (Common Table Expression), который нумерует все строки|
|**ROW_NUMBER() OVER (PARTITION BY email ORDER BY created_at)**|Для каждого email нумерует записи по дате создания (самая старая → 1, следующая → 2, и т.д.)|
|**WHERE email IN (SELECT email FROM users GROUP BY email HAVING COUNT(*) > 1)**|Оставляет только те email, у которых есть дубликаты (встречаются > 1 раза)|
|**ORDER BY email, rn**|Сортирует: сначала по email, потом по номеру строки|

### Что означает результат:
```text
email         | created_at           | rn
test@mail.com | 2024-01-10 10:00:00  | 1   ← первая регистрация
test@mail.com | 2024-02-15 12:00:00  | 2   ← вторая
test@mail.com | 2024-03-20 14:00:00  | 3   ← третья (всего 3 дубликата)
```

- `rn = 1` → **оригинал** (самая старая запись)
- `rn > 1` → **дубликаты** (повторные регистрации)

---
### Для собеседования: ключевые моменты

|Элемент|Зачем используется|
|---|---|
|**CTE (WITH ... AS)**|Упрощает запрос: отделяет нумерацию от фильтрации|
|**ROW_NUMBER()**|Присваивает уникальный номер каждой строке внутри группы (email)|
|**PARTITION BY email**|Группирует по email (каждый email получает свою нумерацию с 1)|
|**ORDER BY created_at**|Определяет порядок нумерации: самый старый = 1|
|**WHERE IN + GROUP BY + HAVING**|Фильтрует только те email, у которых есть дубликаты|

### Как можно улучшить запрос
Если нужно удалить дубликаты, оставив только самый старый:
```sql
WITH numbered AS (
    SELECT *,
           ROW_NUMBER() OVER (PARTITION BY email ORDER BY created_at) AS rn
    FROM users
)
DELETE FROM users
WHERE (email, created_at) IN (
    SELECT email, created_at
    FROM numbered
    WHERE rn > 1
);
```

### Почему это спрашивают на собеседованиях
Этот вопрос проверяет знание:
1. **Оконных функций** (ROW_NUMBER, PARTITION BY, ORDER BY)    
2. **CTE** (WITH ... AS)    
3. **Группировки и агрегации** (GROUP BY, HAVING)    
4. **Подзапросов** (WHERE IN)    
5. Практических задач по очистке данных
