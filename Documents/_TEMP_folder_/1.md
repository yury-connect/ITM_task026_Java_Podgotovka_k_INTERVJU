**Treasury Flow** — это отказоустойчивая микросервисная платформа для казначейского учета, управления мультивалютными портфелями и автоматического расчета налоговой базы с учетом валютной переоценки по алгоритму FIFO. 

Проект разработан для демонстрации компетенций уровня **Middle+ / Senior** в Java Enterprise, интеграциях (REST/SOAP) и асинхронной архитектуре (Event-Driven).

---

## ✨ Ключевые возможности

### 💼 Бизнес-фичи
- **Синхронизация с ЦБ РФ и Биржами:** Автоматическая загрузка официальных курсов валют и учетных цен по SOAP, а также рыночных котировок по REST.
- **Идемпотентный кошелек:** Строгий учет операций (покупки, продажи, дивиденды) без риска двойного списания.
- **Умный налоговый калькулятор (FIFO):** Списание лотов с мгновенным пересчетом в национальную валюту строго по курсу на дату исторической операции.
- **SOAP-шлюз для ERP:** Готовый WSDL-контракт для выгрузки бухгалтерских проводок в 1С или SAP.

### 🛠 Инженерные паттерны (Under the Hood)
- **Database per Service:** 3 изолированные БД PostgreSQL в одном контейнере.
- **Transactional Outbox:** Гарантированная отправка событий в Kafka без риска рассинхрона с БД.
- **Idempotent Consumer:** Защита от семантики *at-least-once* брокера сообщений.
- **Clean Architecture:** Изоляция расчетного ядра на чистой Java 25 (Records, Virtual Threads, Pattern Matching) с контролем через ArchUnit.
- **Security First:** Защита от XXE-уязвимостей при парсинге внешнего XML, маскирование чувствительных данных в логах.

## 🚀 Быстрый старт (Quick Start)

### 1. Требования
Для локального запуска вам потребуется: **JDK 25**, **Maven 3.9+** и **Docker Compose**.

### 2. Сборка контрактов
Скомпилируйте общие DTO и установите их в локальный maven-репозиторий:
```bash
mvn clean install -DskipTests
```

### 3. Запуск инфраструктуры
Поднимите PostgreSQL (с автоматическим созданием БД) и брокер Apache Kafka (в легковесном режиме KRaft):
```bash
docker compose up -d
```
*Убедитесь, что инфраструктура работает, открыв Kafka UI по адресу: [http://localhost:8090](http://localhost:8090)*

### 4. Запуск микросервисов
Запустите приложения из вашей IDE (или через `java -jar`) в любом порядке. Сервисы сами дождутся друг друга благодаря Retry-механизмам:
- `currency-rates-service` (порт `8081`)
- `portfolio-service` (порт `8082`)
- `tax-report-service` (порт `8083`)
