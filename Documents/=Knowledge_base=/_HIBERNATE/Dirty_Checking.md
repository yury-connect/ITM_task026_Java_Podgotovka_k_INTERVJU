# **Dirty Checking** (*Отслеживание грязных состояний*)

- **Механика:** При загрузке сущности в состояние `Managed` Hibernate создает в памяти скрытый базовый снапшот (копию) всех её полей.
  
- При вызове `flush()` или коммите транзакции Hibernate сравнивает текущее состояние объекта с его исходным снапшотом.
  
- Если найдены расхождения, Hibernate **автоматически генерирует и выполняет SQL-запрос `UPDATE`** для измененных полей без необходимости явного вызова каких-либо методов сохранения.
