# Какие *виды* `ThreadPool` существуют?

- **FixedThreadPool** — фиксированное количество потоков, задачи в LinkedBlockingQueue (*осторожно — очередь неограниченная, может OOM*). 
  
- **CachedThreadPool** — создаёт потоки по запросу, простаивающие убивает через 60с, хорош для коротких задач. 
  
- **SingleThreadExecutor** — один поток, гарантирует последовательность. 
  
- **ScheduledThreadPool** — для периодических/отложенных задач. 
  
- **WorkStealingPool** *(Java 8)* — на ForkJoinPool, потоки воруют задачи друг у друга. В продакшене лучше создавать ThreadPoolExecutor вручную с явными параметрами.
