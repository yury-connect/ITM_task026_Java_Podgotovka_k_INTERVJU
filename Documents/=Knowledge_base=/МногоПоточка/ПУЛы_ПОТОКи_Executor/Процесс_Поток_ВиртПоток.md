# Процесс - Поток - Виртуальный поток
## Кратко о различиях

---
### ⚙️ **Процесс** (*Process*)

- **Что:** Изолированная программа со своим адресным пространством    
- **Ресурсы:** Своя память, свои файлы, свои данные    
- **Вес:** Тяжёлый (изоляция дорогая)    
- **ОС:** Управляется ОС, полная изоляция    
- **Накладные расходы:** Огромные (свой контекст, своя память)    
```bash
# Каждое приложение - это процесс
ps aux  # список процессов
```

---
### 🧵 **Поток** (*Thread*)

- **Что:** Единица выполнения внутри одного процесса    
- **Ресурсы:** Общие (память, файлы) с другими потоками того же процесса    
- **Вес:** Лёгкий (по сравнению с процессом)    
- **ОС:** Управляется ОС (планировщик)    
- **Накладные расходы:** Высокие (стек ~1 МБ, создание дорогое)   
```java
Thread t = new Thread(() -> System.out.println("Hello"));
t.start();
```

---
### 🌿 **Виртуальный поток** (*Virtual Thread*)

- **Что:** Облегчённая версия потока (Java 21+, Project Loom)    
- **Ресурсы:** Почти не занимают память (стек на куче)    
- **Вес:** Очень лёгкий (миллионы можно создать)    
- **ОС:** Управляется JVM, НЕ ОС (монтируется на Carrier Thread)    
- **Накладные расходы:** Минимальные    
```java
Thread.startVirtualThread(() -> System.out.println("Hello"));
```

---
## Сравнительная таблица

| Характеристика    | Процесс                | Поток                   | Виртуальный поток     |
| ----------------- | ---------------------- | ----------------------- | --------------------- |
| **Память**        | Изолированная, своя    | ~1 МБ на стек           | ~KB (на куче)         |
| **Создание**      | Очень дорогое          | Дорогое                 | Дешёвое               |
| **Количество**    | Сотни                  | Тысячи                  | Миллионы              |
| **Переключение**  | ОС планирует           | ОС планирует            | JVM планирует         |
| **Изоляция**      | Есть (полная)          | Нет (делят память)      | Нет (делят память)    |
| **Использование** | Микросервисы, изоляция | Традиционные приложения | Высоконагруженные I/O |

---
## Пример из реального мира

| Концепция             | Аналогия                                                                         |
| --------------------- | -------------------------------------------------------------------------------- |
| **Процесс**           | 🏢 **Здание** — своё адрес, своя инфраструктура                                  |
| **Поток**             | 👷 **Рабочие в одном здании** — делят столовую, туалеты, но работают параллельно |
| **Виртуальный поток** | 🤖 **Роботы-курьеры** — легче, быстрее, их может быть много в одном здании       |

---
## Когда использовать?

| Инструмент             | Для чего                                                        |
| ---------------------- | --------------------------------------------------------------- |
| **Процессы**           | Микросервисы, изолированные приложения, безопасность            |
| **Потоки**             | Классические многопоточные приложения (общие данные, CPU-bound) |
| **Виртуальные потоки** | I/O-операции, веб-сервера с тысячами запросов                   |

---
## Вывод

**Вес:** Виртуальный поток < Поток << Процесс  
**Изоляция:** Процесс >>> Поток = Виртуальный поток  
**Количество:** Виртуальные потоки > Потоки >>> Процессы
