## 🧵 Потоки-демоны (Daemon) vs Обычные (User)

| Характеристика     | **Обычный поток (User)**                                             | **Поток-демон (Daemon)**                                                                                |
| ------------------ | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Жизненный цикл** | Живёт, пока не завершится сам                                        | Живёт, пока жива JVM                                                                                    |
| **Завершение JVM** | **Блокирует** завершение JVM (ждёт, пока все User-потоки закончатся) | **Не блокирует** завершение JVM (если остались только демоны — JVM завершается, даже если они работают) |
| **Назначение**     | Выполнение **основной бизнес-логики**                                | Выполнение **фоновых/сервисных задач** (не критичных для работы приложения)                             |
| **Примеры**        | Main, потоки обработки запросов, Worker'ы                            | Garbage Collector (GC), Finalizer, фоновый мониторинг, логгеры                                          |
| **Наследование**   | Дочерний поток **наследует** daemon-статус родителя                  | Дочерний поток **наследует** daemon-статус родителя                                                     |
| **Как создать**    | По умолчанию (`new Thread()`)                                        | `thread.setDaemon(true);` **ДО** `thread.start()`                                                       |
| **Прерывание**     | Может быть прерван через `interrupt()`                               | Может быть прерван через `interrupt()` (но JVM может завершиться до этого)                              |
| **Использование**  | **Основные задачи** (API, БД, бизнес-логика)                         | **Сервисные задачи** (кэширование, очистка, сбор статистики)                                            |

## 📊 Визуальное сравнение

```text
         JVM
           │
      ┌────┴────────────────────────────┐
      │                                 │
      ▼                                 ▼
┌──────────────┐              ┌─────────────────┐
│ User Thread  │              │  Daemon Thread  │
│ (основной)   │              │  (фоновый)      │
│              │              │                 │
│ - Main       │              │ - GC            │
│ - API Worker │              │ - Finalizer     │
│ - БД-запросы │              │ - Мониторинг    │
└──────────────┘              └─────────────────┘
      │                                 │
      │ ❌ Блокирует завершение JVM     │ ✅ НЕ блокирует
      │    (ждёт, пока завершится)      │    (JVM закроется, даже если работает)
      │                                 │
      └────────────────┬────────────────┘
                       ▼
                 JVM завершается
```

## ⚠️ Важные нюансы (*для собеседования*)

### 1️⃣ Нельзя превратить **демона обратно** в обычный

Если поток уже запущен (`start()` вызван), метод `setDaemon()` выбросит `IllegalThreadStateException`.
```java
Thread t = new Thread(() -> {});
t.setDaemon(true);  // ✅ ДО старта
t.start();          // ✅
// t.setDaemon(false); // ❌ IllegalThreadStateException!
```
> **Нельзя изменить** *daemon-статус* потока (*ни вкл., ни выкл*.) ПОСЛЕ того, как поток был запущен (`start()`).

---
### 2️⃣ Демоны **не гарантируют** выполнение критических операций

Если JVM завершается (потому что остались только демоны), она **не ждёт**, пока демоны закончат запись в файл или БД.

**Опасность:**
```java
Thread daemon = new Thread(() -> {
    // Запись в файл
    writeToFile("Важные данные");
    // ❌ JVM может завершиться ДО окончания записи!
});
daemon.setDaemon(true);
daemon.start();
```

**Решение:** Не использовать демоны для критичных операций (сохранение, транзакции).

---
### 3️⃣ **Демоны полезны для фоновых задач**

- Очистка кэша.    
- Сбор статистики (метрик).    
- Мониторинг состояния системы.

---
## 🎤 Идеальный ответ на собеседовании (одной фразой)

> _«Потоки-демоны — это фоновые потоки, которые не мешают JVM завершиться. Они нужны для выполнения сервисных задач, таких как GC или мониторинг. Обычные пользовательские потоки, наоборот, блокируют завершение JVM до своего окончания. Демонами нельзя делать критичные операции, требующие гарантированного завершения.»_
