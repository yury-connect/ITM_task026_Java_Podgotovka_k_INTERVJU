## **Обработка ошибок в Spring (@ControllerAdvice, @ExceptionHandler)**

---
### **Базовый уровень (@ExceptionHandler внутри контроллера)**
```java
@RestController
public class UserController {
    
    @GetMapping("/users/{id}")
    public User getUser(@PathVariable Long id) {
        // логика
    }
    
    // Обработка ошибки внутри контроллера
    @ExceptionHandler(UserNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(UserNotFoundException ex) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
            .body(new ErrorResponse(ex.getMessage()));
    }
}
```
**Минус:** Обработчик живет только в этом контроллере.

---
### **Глобальный уровень (@ControllerAdvice)**

> **Суть:** Единый центр обработки ошибок для ВСЕХ контроллеров.

java

@RestControllerAdvice // = @ControllerAdvice + @ResponseBody
public class GlobalExceptionHandler {
    
    // Обработка конкретного исключения
    @ExceptionHandler(UserNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(UserNotFoundException ex) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
            .body(new ErrorResponse("USER_NOT_FOUND", ex.getMessage()));
    }
    
    // Обработка валидации
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> handleValidation(MethodArgumentNotValidException ex) {
        Map<String, String> errors = ex.getBindingResult()
            .getFieldErrors()
            .stream()
            .collect(Collectors.toMap(
                FieldError::getField,
                FieldError::getDefaultMessage
            ));
        return ResponseEntity.badRequest()
            .body(new ErrorResponse("VALIDATION_ERROR", errors));
    }
    
    // Обработка всех остальных ошибок (fallback)
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleAll(Exception ex) {
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
            .body(new ErrorResponse("SERVER_ERROR", ex.getMessage()));
    }
}

**Важно:**

- `@RestControllerAdvice` = `@ControllerAdvice` + `@ResponseBody`
    
- Можно использовать несколько `@ControllerAdvice` с разными приоритетами (`@Order`)
    
- Spring сам выбирает наиболее подходящий обработчик (самый конкретный)

### **Дополнительные возможности:**

**1. Использование ResponseStatus**

java

@ResponseStatus(HttpStatus.NOT_FOUND)
public class UserNotFoundException extends RuntimeException {
    // автоматически вернет 404
}

**2. Использование Problem Detail (RFC 7807)**

java

@ExceptionHandler(UserNotFoundException.class)
public ProblemDetail handleNotFound(UserNotFoundException ex) {
    ProblemDetail pd = ProblemDetail.forStatus(HttpStatus.NOT_FOUND);
    pd.setTitle("User not found");
    pd.setDetail(ex.getMessage());
    pd.setProperty("timestamp", LocalDateTime.now());
    return pd;
}
