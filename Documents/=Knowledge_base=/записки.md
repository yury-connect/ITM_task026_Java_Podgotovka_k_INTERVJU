### 🌐 **Открытые** эндпоинты (*без аутентификации*)

| Метод  | Путь                   | Назначение                                                                                        |
| ------ | ---------------------- | ------------------------------------------------------------------------------------------------- |
| `POST` | `/api/v1/auth/token`   | Аутентификация по логину/паролю, выдача JWT                                                       |
| `POST` | `/api/v1/auth/refresh` | Обновление JWT-токена по refresh-токену.                                                          |
| `GET`  | `/api/v1/health`       | Health-check для мониторинга (Render, клиенты)                                                    |
| `GET`  | `/api/v1/info`         | Базовая справочная информация о сервисе (*версия API, название, контакты, доступные возможности*) |
|        |                        |                                                                                                   |

### 🔒 **Защищённые** эндпоинты (*требуют JWT*)

#### Списки и источники

| Метод | Путь                             | Назначение                                                                                   |
| ----- | -------------------------------- | -------------------------------------------------------------------------------------------- |
| `GET` | `/api/v1/lists`                  | Список **доступных** источников/ списков (id, displayName, description, tags, questionCount) |
| `GET` | `/api/v1/lists/{listId}`         | Метаданные конкретного источника (описание, topics, questionCount, lastSyncedAt)             |
| `GET` | `/api/v1/lists/{listId}/version` | Текущая версия данных источника (для проверки необходимости обновления клиентского кэша)     |

#### Вопросы

| Метод | Путь                                            | Назначение                        |
| ----- | ----------------------------------------------- | --------------------------------- |
| `GET` | `/api/v1/lists/{listId}/questions`              | Все вопросы списка (с пагинацией) |
| `GET` | `/api/v1/lists/{listId}/questions/{questionId}` | Конкретный вопрос по ID           |
| `GET` | `/api/v1/lists/{listId}/questions/count`        | Количество вопросов в списке      |

#### Синхронизация и кэш (административные)

| Метод  | Путь                                        | Назначение                                               |
| ------ | ------------------------------------------- | -------------------------------------------------------- |
| `POST` | `/api/v1/admin/lists/{listId}/refresh`      | Принудительно обновить кэш источника (только для админа) |
| `GET`  | `/api/v1/admin/lists/{listId}/cache-status` | Статус кэша (последняя синхронизация, ошибки)            |

---
## ## Структура URL
```text
/api/v1
├── /auth
│   └── POST /token                          # Открытый
├── /health                                  # Открытый
├── /lists                                   # Открытый (публичные) / Защищённый (все)
│   └── /{listName}
│       ├── GET                              # Метаданные источника
│       ├── GET /version                     # Версия данных (для кэша)
│       └── /questions
│           ├── GET                          # Все вопросы (с пагинацией)
│           ├── GET /count                   # Количество вопросов
│           └── GET /{questionId}            # Конкретный вопрос
└── /admin
    └── /lists/{listName}
        ├── POST /refresh                    # Принудительная синхронизация
        └── GET /cache-status                # Статус кэша
```
