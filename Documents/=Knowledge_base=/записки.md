### 🌐 Открытые эндпоинты (без аутентификации)

|Метод|Путь|Назначение|
|---|---|---|
|`POST`|`/api/v1/auth/token`|Аутентификация по логину/паролю, выдача JWT|
|`GET`|`/api/v1/health`|Health-check для мониторинга (Render, клиенты)|
|`GET`|`/api/v1/lists`|Список **публичных** источников (id, displayName, description, tags, questionCount)|

---
### 🔒 Защищённые эндпоинты (требуют JWT)

#### Списки и источники

| Метод | Путь                               | Назначение                                                                               |
| ----- | ---------------------------------- | ---------------------------------------------------------------------------------------- |
| `GET` | `/api/v1/lists`                    | Список **всех** доступных источников                                                     |
| `GET` | `/api/v1/lists/{listNId}`          | Метаданные конкретного источника (описание, topics, questionCount, lastSyncedAt)         |
| `GET` | `/api/v1/lists/{listName}/version` | Текущая версия данных источника (для проверки необходимости обновления клиентского кэша) |

#### Вопросы

|Метод|Путь|Назначение|
|---|---|---|
|`GET`|`/api/v1/lists/{listName}/questions`|Все вопросы списка (с пагинацией)|
|`GET`|`/api/v1/lists/{listName}/questions/{questionId}`|Конкретный вопрос по ID|
|`GET`|`/api/v1/lists/{listName}/questions/count`|Количество вопросов в списке|

#### Синхронизация и кэш (административные)

|Метод|Путь|Назначение|
|---|---|---|
|`POST`|`/api/v1/admin/lists/{listName}/refresh`|Принудительно обновить кэш источника (только для админа)|
|`GET`|`/api/v1/admin/lists/{listName}/cache-status`|Статус кэша (последняя синхронизация, ошибки)|
