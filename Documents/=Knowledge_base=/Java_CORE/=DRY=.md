**DRY** (аббревиатура от **«Don't Repeat Yourself»** — _«Не повторяйся»_) — фундаментальный принцип разработки ПО, требующий избегать дублирования информации и логики.

### 🎯 В чём суть?
Каждый элемент знаний или логики в системе должен иметь **единственное, однозначное и авторитетное представление**.

Если один и тот же алгоритм, формула или бизнес-правило скопированы в несколько мест программы (Copy-Paste), изменение этой логики в будущем потребует правок во всех этих местах.

### ❌ Пример нарушения DRY
Проверка email-адреса продублирована в нескольких сервисах:
```Java
// В UserService.java
if (email == null || !email.contains("@")) {
    throw new IllegalArgumentException("Некорректный email");
}

// В OrderService.java
if (email == null || !email.contains("@")) {
    throw new IllegalArgumentException("Некорректный email");
}
```
- **Проблема:** Если правило валидации изменится (например, понадобится регулярное выражение), придется искать и править все места в проекте. Одно упущенное место приведет к багу.

### ✅ Соблюдение DRY
Логика вынесена в единый переиспользуемый метод/класс:
```Java
public class ValidationUtils {
    public static void validateEmail(String email) {
        if (email == null || !email.contains("@")) {
            throw new IllegalArgumentException("Некорректный email");
        }
    }
}

// В любых сервисах:
ValidationUtils.validateEmail(email);
```

### ⚠️ Подвох: Ложное дублирование (Dry vs Kiss)
Слепое следование DRY может навредить. Если два кусочка кода выглядят одинаково, но **меняются по разным причинам** (относятся к разной бизнес-логике), их объединение создаст жесткую связность (Tight Coupling). В таких случаях лучше оставить дублирование, чем создавать ложную абстракцию.

### 🎤 Короткая шпаргалка для собеседования
> «Принцип DRY (Don't Repeat Yourself) означает, что каждая деталь логики или знаний должна быть описана в системе ровно в одном месте. Избегая дублирования кода, мы упрощаем его поддержку: при изменении требований нужно поправить код только в одном месте, а не искать дубликаты по всему проекту.»
