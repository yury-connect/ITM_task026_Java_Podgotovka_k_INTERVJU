# Массив в java - объектом какого класса является?

---
**Массив в Java является объектом класса, который генерируется JVM автоматически.**

### Коротко и точно
- Любой массив (*и примитивный, и объектный*) — это **объект**.
- Он **наследует** от класса `java.lang.Object`.
- У него есть поле *length* и методы, унаследованные от *Object* (*toString(), equals(), hashCode(), getClass() и т.д.*).

### Какой именно класс?
JVM создаёт **специальный класс** для каждого типа массива:

| Тип массива            | Класс (*что возвращает <br>`getClass().getName()`*) | Пример           |
| ---------------------- | --------------------------------------------------- | ---------------- |
| `int[]`                | `[I`                                                | `int[].class`    |
| `double[]`             | `[D`                                                |                  |
| `boolean[]`            | `[Z`                                                |                  |
| `String[]`             | `[Ljava.lang.String;`                               | `String[].class` |
| `Object[]`             | `[Ljava.lang.Object;`                               |                  |
| i`nt[][]`(*двумерный*) | `[[I`                                               |                  |

Это **не** обычные классы, которые ты пишешь сам.  
Это **синтетические классы**, которые создаёт JVM во время выполнения.

### Как проверить
```Java
int[] arr = new int[5];
System.out.println(arr.getClass());           // class [I
System.out.println(arr.getClass().getName()); // [I
System.out.println(arr instanceof Object);    // true
System.out.println(arr.getClass().getSuperclass()); // class java.lang.Object
```

```Java
String[] strs = new String[3];
System.out.println(strs.getClass().getName()); // [Ljava.lang.String;
```

### Важные моменты
1. **Массив — всегда объект**, даже если содержит примитивы (*int[], boolean[] и т.д.*).
2. Он лежит в **Heap**, а не в Stack.
3. У него есть публичное *final*-поле *length*.
4. Методы *clone(), toString(), equals() и hashCode()* у массивов **не переопределены** осмысленно (*кроме clone() — он делает поверхностную копию*).
5. Массивы **ковариантны**: String[] является подтипом Object[].

### Вывод
Массив в Java — это **объект**, который наследует от Object, а его конкретный класс генерируется JVM (например, `[I` для `int[]`, `[Ljava.lang.String;` для `String[]`).

|Тип массива|Что возвращает getClass().getName()|Пояснение|
|---|---|---|
|int[]|**[I**|Массив **примитивов** int|
|Integer[]|**[Ljava.lang.Integer;**|Массив **объектов** Integer|
|String[]|[Ljava.lang.String;|Массив объектов|
|double[]|[D|Примитивы|
|boolean[]|[Z|Примитивы|
|long[]|[J|Примитивы|
|byte[]|[B|Примитивы|
|char[]|[C|Примитивы|
|float[]|[F|Примитивы|
|short[]|[S|Примитивы|

### Почему именно `[I`?

Это **специальная нотация JVM** (*internal name*):
- `[` — означает «массив»
- `I` — означает примитивный тип int
- `L...;` — означает ссылочный тип (класс)

Поэтому:
- `int[]` → `[I`
- `Integer[]` → `[Ljava.lang.Integer;`

### Проверка кодом
```Java
int[] primitive = new int[5];
Integer[] boxed = new Integer[5];

System.out.println(primitive.getClass().getName()); // [I
System.out.println(boxed.getClass().getName());     // [Ljava.lang.Integer;

System.out.println(primitive.getClass());           // class [I
System.out.println(boxed.getClass());               // class [Ljava.lang.Integer;
```

### Итог
- `int[]` → класс **`[I`**
- `Integer[]` → класс **[Ljava.lang.Integer;**

Это разные вещи. int[] и Integer[] — совершенно разные типы в Java.
