> **Замыкание** — это когда функция «забирает с собой» значения всех нужных ей переменных из внешнего мира, чтобы пережить своего создателя.

**В Java это выглядит так:** Лямбда не видит переменные извне "вживую". Она видит только их **замороженные копии**, которые были сделаны в момент создания лямбды.
