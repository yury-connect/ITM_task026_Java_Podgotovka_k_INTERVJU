# Java versions 

**Шестимесячный цикл.** Java перешла на модель релизов каждые **6 месяцев** (в марте и сентябре) начиная с 2017 года [](https://dev.java/evolution/?utm_campaign=DeveloPassion%27s%20Newsletter&utm_medium=email&utm_source=Revue%20newsletter)[](https://docs.oracle.com/en/java/javase/24/install/version-string-format.html#JSJIG-GUID-DCA60310-6565-4BB6-8D24-6FF07C1C4B4E). Это стандарт де-факто для современной Java.

**Список LTS.** Актуальные LTS-версии: **8, 11, 17, 21, 25** [](https://yum.oracle.com/oracle-linux-java.html)[](https://ubuntu.com/project/docs/maintainers/niche-package-maintenance/openjdk/)[](https://safeguard.sh/resources/blog/java-lts).
- **Java 8** → Март 2014    
- **Java 11** → Сентябрь 2018 (**прошло 4,5 года**)    
- **Java 17** → Сентябрь 2021 (**прошло 3 года**)    
- **Java 21** → Сентябрь 2023 (**прошло 2 года**)    
- **Java 25** → Сентябрь 2025 (**прошло 2 года**)

### Разница между **LTS** и **Feature-релизом**. 
	
- **LTS (Long-Term Support):** Получает обновления безопасности и исправления ошибок в течение **многих лет** (*от **8** лет и больше*). Именно эти версии выбирают для продакшена [](https://yum.oracle.com/oracle-linux-java.html)[](https://safeguard.sh/resources/blog/java-lts).
    
- **Feature-релиз (не-LTS):** Живёт **всего 6 месяцев** — до выхода следующего релиза. После этого обновления для него прекращаются. Предназначен для тестирования новых фич [](https://gitverse.ru/blog/news/vypusk-java-se-26-i-openjdk-26-proekt-po-integracii-podderzhki-javascript-i-python-v-jvm#1)[](https://www.jrebel.com/blog/java-lts).

**Сроки поддержки конкретных LTS (примерно):**

- **Java 11:** до 2032[](https://gitverse.ru/blog/news/vypusk-java-se-26-i-openjdk-26-proekt-po-integracii-podderzhki-javascript-i-python-v-jvm#1)

- **Java 21:** до 2031[](https://yum.oracle.com/oracle-linux-java.html)[](https://gitverse.ru/blog/news/vypusk-java-se-26-i-openjdk-26-proekt-po-integracii-podderzhki-javascript-i-python-v-jvm#1)    
- **Java 25:** до 2033

### 🎤 Как ответить на собеседовании 
> _«С 2017 года Java перешла на модель релизов каждые **6** месяцев. Раз в 2–3 года выходит LTS-версия, которая получает поддержку и обновления безопасности в течение многих лет. Актуальные LTS сейчас — это 8, 11, 17, 21 и 25. Все промежуточные версии — это Feature-релизы, которые живут всего **полгода** и нужны для тестирования новых возможностей. Для продакшена всегда выбирают LTS.»_
