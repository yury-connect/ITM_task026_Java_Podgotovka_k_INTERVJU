`@Transactional` — это ваш главный инструмент для управления транзакциями в Spring. Он определяет, как и когда должны открываться, коммититься или откатываться транзакции базы данных[](https://www.baeldung.com/spring-transactional-propagation-isolation).

### 🔄 Все режимы **Propagation** (*Поведение транзакций)*
Этот параметр определяет, как метод должен реагировать на существующую транзакцию[](https://www.baeldung.com/spring-transactional-propagation-isolation). `REQUIRED` используется по умолчанию.
	
- **`REQUIRED`**: Поддерживает текущую транзакцию. Если её нет, создает **новую**.
    
- **`REQUIRES_NEW`**: Всегда создает **новую** транзакцию. Если есть текущая, она приостанавливается (suspend).
    
- **`SUPPORTS`**: Поддерживает текущую транзакцию. Если её нет, выполняется без транзакции.
    
- **`NOT_SUPPORTED`**: Выполняется **без** транзакции. Если есть текущая, она приостанавливается.
    
- **`NESTED`**: Выполняется во **вложенной** транзакции, если есть текущая (использует savepoint). Если нет — ведет себя как `REQUIRED`.
    
- **`MANDATORY`**: Обязательно должен быть вызван в рамках **существующей** транзакции. Если её нет, бросает исключение.
    
- **`NEVER`**: Выполняется **без** транзакции. Если есть текущая, бросает исключение.

> **Важные нюансы**:
> 
> 1. **Приостановка (`suspend`)**: Режимы `REQUIRES_NEW` и `NOT_SUPPORTED` приостанавливают текущую транзакцию. Эта функция зависит от конкретного менеджера транзакций и может работать не везде (например, требует настройки `JtaTransactionManager`).
>     
> 2. **Вложенность (`NESTED`)**: Реально работает только с `DataSourceTransactionManager` (JDBC). Для JTA требуется поддержка со стороны провайдера.

### 💡 Коротко о главном

- **Настройки `isolation`, `timeout` работают только для новых транзакций**: Если вы выставите высокий уровень изоляции на методе с `propagation = Propagation.REQUIRED`, но он будет вызван из другого метода, уже открывшего транзакцию, ваша настройка будет проигнорирована[](https://docs.spring.io/spring-framework/docs/5.3.0/javadoc-api/org/springframework/transaction/annotation/Transactional.html).
    
- **`readOnly` - это подсказка**: Это не жесткая гарантия. База данных и Hibernate могут использовать этот флаг для оптимизации, но не всегда блокируют запись[](https://docs.spring.io/spring-framework/docs/5.3.0/javadoc-api/org/springframework/transaction/annotation/Transactional.html)[](https://www.baeldung.com/spring-vs-jta-transactional).
