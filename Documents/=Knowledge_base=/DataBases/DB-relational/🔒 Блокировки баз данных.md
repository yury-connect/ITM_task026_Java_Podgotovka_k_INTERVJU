# ![🔒](https://m.vk.ru/emoji/e/f09f9492.png) **Блокировки баз данных**: ключевые различия

**Блокировка** — временное ограничение на выполнение некоторых операций обработки данных. Она предотвращают одновременный доступ к данным для обеспечения целостности и консистентности данных.

  ![|640x829](./_Attachments_🔒_Блокировки_баз_данных/Блокировки_БД.jpg)

### ![📌](https://m.vk.ru/emoji/e/f09f938c.png) Основные типы:
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Shared Lock**: позволяет нескольким транзакциям одновременно читать ресурс, но не модифицировать его  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Exclusive Lock**: позволяет транзакции как читать, так и модифицировать ресурс  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Update Lock**: используется для предотвращения взаимоблокировки, когда транзакция намеревается обновить ресурс  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Schema Lock**: используется для защиты структуры объектов базы данных  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Bulk Update Lock**: используется во время массовых вставок  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Key-Range Lock**: используется в индексированных данных для предотвращения фантомных чтений  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Row-Level Lock**: блокирует конкретную строку в таблице  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Page-Level Lock**: блокирует конкретную страницу (фиксированный блок данных) в базе данных  
![🔷](https://m.vk.ru/emoji/e/f09f94b7.png) **Table-Level Lock**: блокирует всю таблицу
