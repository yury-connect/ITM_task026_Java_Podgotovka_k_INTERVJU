# 🔍 Index Scan vs Index Only Scan — супер-кратко

---
### 📌 **Index Scan (Сканирование индекса)**
1. Находит в индексе **адреса** (TID) нужных строк.    
2. Идёт **в таблицу** (heap) по этим адресам, чтобы прочитать остальные данные.    
3. Дополнительная операция: **обращение к таблице** (heap access).    

**Используется:** Когда в `SELECT` есть колонки, которых **нет в индексе**.

---
### 📌 **Index Only Scan (Сканирование только индекса)**
1. Находит в индексе **все нужные данные** сразу.    
2. **Не обращается к таблице** (heap), потому что всё уже есть в индексе.    
3. **Быстрее**, чем Index Scan.    

**Используется:** Когда все колонки из `SELECT` и `WHERE` **покрываются индексом** (Covering Index).

---
### 🎯 **Главное отличие (одной фразой)**

> **Index Scan** — идёт в таблицу за данными.  
> **Index Only Scan** — берёт всё из индекса, таблицу **не трогает**.

> 💡 **Index Only Scan** — это **всегда быстрее**, потому что не требует чтения самой таблицы.  
> 📌 Появляется, когда создан **покрывающий индекс** (`CREATE INDEX ... INCLUDE (col)`).
