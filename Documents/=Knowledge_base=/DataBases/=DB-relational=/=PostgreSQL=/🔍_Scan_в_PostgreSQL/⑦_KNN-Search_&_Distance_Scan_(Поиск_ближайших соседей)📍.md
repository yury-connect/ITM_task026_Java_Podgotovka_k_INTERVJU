# ⑦ KNN-Search / Distance Scan <br>(*Поиск ближайших соседей*) 📍

Специализированное сканирование по пространственным индексам (**GiST** / **hnsw** / **ivfflat**).

- ⚙️ **Принцип работы:** Использует оператор расстояния (`<->` или `<=>`). Индекс сразу возвращает элементы в порядке увеличения физического или векторного расстояния от заданной точки, не вычисляя расстояние для каждой строки таблицы.
    
- 🎯 **Для чего он:** Гео-поиск («найти 5 ближайших ресторанов к координатам пользователя») и Vector Search / AI («найти топ-10 похожих векторов/эмбеддингов»).
    
- ⚡ **Сложность:** `O(log N + K)` (где $K$ — количество ближайших соседей).
    
- 🟢 **Плюсы:** Возвращает строго отсортированные $K$ элементов мгновенно без полной сортировки всей таблицы (`ORDER BY ... LIMIT K`).
    
- 🔴 **Минусы:** Требует специфических индексов (GiST / PostGIS / pgvector).
    
- 📌 **Когда происходит:** При запросах вида `ORDER BY location <-> point '(X, Y)' LIMIT 10`.
