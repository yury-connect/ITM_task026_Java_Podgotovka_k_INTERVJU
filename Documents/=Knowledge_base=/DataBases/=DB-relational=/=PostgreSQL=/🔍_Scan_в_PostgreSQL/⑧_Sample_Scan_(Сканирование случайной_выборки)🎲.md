# ⑧ Sample Scan <br>(*Сканирование случайной выборки*) 🎲

Считывание не всех строк, а случайного процента страниц или записей таблицы.

- ⚙️️ **Принцип работы:** Используется секция `TABLESAMPLE (SYSTEM | BERNOULLI)`. `SYSTEM` случайным образом выбирает блоки страниц (быстро), а `BERNOULLI` проверяет случайным образом каждую строку (медленнее, но точнее).
    
- 🎯 **Для чего он:** Для мгновенного получения репрезентативной выборки данных без прохода по всей таблице (например, для статистики или A/B тестов).
    
- ⚡ **Сложность:** `O(P)` (где $P$ — процент запрашиваемых с диска страниц).
    
- 🟢 **Плюсы:** Работает за доли миллисекунды даже на терабайтных таблицах.
    
- 🔴 **Минусы:** Не подходит, если нужна точная детерминированная выборка.
    
- 📌 **Когда происходит:** При явном вызове `SELECT * FROM users TABLESAMPLE BERNOULLI(1)`.
