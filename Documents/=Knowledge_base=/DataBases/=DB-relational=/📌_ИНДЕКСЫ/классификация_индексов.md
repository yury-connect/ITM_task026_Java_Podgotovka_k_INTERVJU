

```text
ИНДЕКСЫ (классификация 1)
│
├── По структуре данных
│   ├── B-Tree
│   ├── Hash
│   ├── GIN
│   ├── GiST
│   └── BRIN
│
└── По способу организации / применения
    ├── По количеству колонок
    │   ├── Одноколоночные
    │   └── Составные
    │
    ├── По содержимому
    │   └── Покрывающие
    │
    ├── По способу формирования
    │   └── Функциональные
    │
    ├── По множеству индексируемых строк
    │   └── Частичные
    │
    └── По организации хранения
        ├── Кластерные
        └── Некластерные
```

**Главная мысль:**  
- `B-Tree`, `Hash`, `GIN` — **структура индекса**;  
- `Composite`, `Partial`, `Functional`, `Covering`, `Clustered` — **различные свойства/способы организации**
