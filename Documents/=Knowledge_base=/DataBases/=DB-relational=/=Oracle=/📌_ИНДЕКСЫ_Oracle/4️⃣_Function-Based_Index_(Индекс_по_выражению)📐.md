# 4️⃣ Function-Based Index (*Индекс по выражению*) 📐

Индекс, строящийся на основе результата вычисления функции или SQL-выражения над колонкой.

- ⚙️️ **Принцип работы:** Oracle вычисляет значение функции при записи/обновлении строки и заносит результат в дерево B-Tree.
    
- 🎯 **Для чего он:** Для поиска без учета регистра (`WHERE UPPER(last_name) = 'SMITH'`) или арифметических выражений над полями.
    
- ⚡ **Сложность:** Поиск: $O(\log N)$. Вставка: $O(\log N) + \text{вычисление функции}$.
    
- 🟢 **Плюсы:** Избавляет от необходимости переписывать колонки в БД; предотвращает сканирование всей таблицы (`Full Table Scan`) при вызовах функций.
    
- 🔴 **Минусы:** Нагружает CPU при операциях записи; сработает только при точечном совпадении функции в SQL.
    
- 📌 **Когда брать:** Постоянно используются функции `UPPER()`, `LOWER()`, `TRUNC()`, `TO_CHAR()` в секции `WHERE`.
    
- 🛑 **Когда НЕ брать:** Если выражение можно предварительно нормализовать на стороне приложения до сохранения в БД.
