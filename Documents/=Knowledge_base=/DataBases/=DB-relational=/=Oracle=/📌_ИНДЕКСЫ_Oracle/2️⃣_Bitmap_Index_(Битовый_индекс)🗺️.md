# 2️⃣ Bitmap Index (*Битовый индекс*) 🗺️

Уникальная архитектура Oracle для аналитических систем (DWH / OLAP).

- ⚙️ **Принцип работы:** Для каждого уникального значения колонки создается битовая строка (string of bits), где каждый бит соответствует строке таблицы (`1` — значение есть, `0` — нет).
    
- 🎯 **Для чего он:** Для колонок с очень низкой селективностью (пол, статус, регион) и сложной комбинации `AND` / `OR` / `NOT` условий.
    
- ⚡ **Сложность:** Поиск и побитовая комбинация: $O(1)$ на уровень битовых карт + быстрый скан.
    
- 🟢 **Плюсы:** Невероятно компактен; позволяет за доли миллисекунды пересекать битовые карты по нескольким колонкам.
    
- 🔴 **Минусы:** **Катастрофические блокировки на запись!** Блокирует сразу весь блок таблицы при `UPDATE`/`INSERT`, парализуя параллельные транзакции.
    
- 📌 **When брать:** В хранилищах данных (DWH / Data Marts) на таблицах, доступных строго для чтения (`SELECT`).
    
- 🛑 **Когда НЕ брать:** В OLTP-системах с высокой параллельной нагрузкой на запись (`INSERT`/`UPDATE`).
