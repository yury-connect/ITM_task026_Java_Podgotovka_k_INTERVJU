# 6️⃣ Bitmap Join Index (*Составной битовый индекс соединений*) 🔗

Продвинутая конструкция Oracle, индексирующая результат соединения (JOIN) нескольких таблиц!

- ⚙️ **Принцип работы:** Заранее вычисляет и строит битовую карту для таблицы фактов, но на основе значений из справочника (Dimension Table).
    
- 🎯 **Для чего он:** Для оптимизации сложных JOIN-запросов в схемах типа «Звезда» (Star Schema).
    
- ⚡ **Сложность:** Поиск: $O(1)$ по битовой карте.
    
- 🟢 **Плюсы:** Позволяет отфильтровать гигантскую таблицу фактов по текстовым атрибутам измерения вообще без выполнения физического `JOIN` во время запроса!
    
- 🔴 **Минусы:** Падение производительности и жестокие блокировки при любых изменениях в связанных таблицах.
    
- 📌 **Когда брать:** В больших витринах данных (DWH) для денормализованной аналитики.
    
- 🛑 **Когда НЕ брать:** В системах с модификацией данных транзакционного типа.
