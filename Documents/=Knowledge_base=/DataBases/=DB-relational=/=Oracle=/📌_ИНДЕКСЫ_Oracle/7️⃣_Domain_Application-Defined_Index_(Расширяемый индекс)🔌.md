# 7️⃣ Domain / Application-Defined Index (Расширяемый индекс) 🔌

Тот самый **расширяемый тип индекса** (аналог PostgreSQL GiST/SP-GiST/GIN Framework), поддерживаемый ядром Oracle!

- ⚙️ **Принцип работы:** Позволяет сторонним приложениям или картриджам расширения (Oracle Text, Oracle Spatial) определять кастомные структуры данных и методы их индексации с помощью картриджей `Indextype`.
    
- 🎯 **Для чего он:** Полнотекстовый поиск (Oracle Text), географические и пространственные координаты (Oracle Spatial / SDO_GEOMETRY), XML/JSON данные.
    
- ⚡ **Сложность:** Зависит от реализации конкретного `Indextype`.
    
- 🟢 **Плюсы:** Гибкость; возможность индексировать нестандартные бизнес- типы данных (геометрия, документы).
    
- 🔴 **Минусы:** Накладные расходы на вызовы PL/SQL-картриджей; сложность обслуживания.
    
- 📌 **Когда брать:** Полнотекстовый поиск по документообороту, гео-сервисы, работа со сложной геометрией.
    
- 🛑 **Когда НЕ брать:** Для стандартных реляционных колонок.

### 🎤 Короткая шпаргалка для собеседования

> «В Oracle выделяют 7 базовых видов индексов: **B-Tree** (дефолтный для OLTP и точечного поиска), **Bitmap** (для низкой селективности в DWH, но блокирует запись), **IOT** (таблица, встроенная в индекс), **Function-Based** (для сохраненных вычислений), **Reverse Key** (защита от горячих блоков при монотонной записи), **Bitmap Join Index** (для предвычисленных JOIN в аналитике) и расширяемый **Domain Index** (для spatial и полнотекстового поиска через картриджи).» 🚀
