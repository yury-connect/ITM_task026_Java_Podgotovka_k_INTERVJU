public class StaticQuest {

    }
    public static void main(String[] args) {
        new StaticQuest();
    }

## 6/6: Каким будет результат компиляции и выполнения программы?

- BSC    
- CBS    
- SBC    
- CSB    
- SCB

---
Правильный ответ: **SBC** (третий вариант).

**Объяснение:**

Чтобы понять результат, нужно знать порядок инициализации в Java. Он строго регламентирован:

1. **Статическая инициализация (выполняется один раз при загрузке класса):**
    - Сначала выполняется статический блок инициализации (строки 5-7). Он печатает **`S`**.
    
2. **Запуск метода `main`:**	    
    - Начинается выполнение программы. Вызывается `new StaticQuestion()`.
    
3. **Инициализация экземпляра (выполняется при каждом создании объекта):**
    - Перед тем как выполнится код конструктора, выполняются блоки инициализации экземпляра (строки 2-4) в порядке их следования. Печатается **`B`**.
        
    - После этого вызывается сам конструктор (строки 8-10). Печатается **`C`**.        

**Итоговая последовательность:** сначала **S**, затем **B**, затем **C**. Вместе получается **SBC**.
