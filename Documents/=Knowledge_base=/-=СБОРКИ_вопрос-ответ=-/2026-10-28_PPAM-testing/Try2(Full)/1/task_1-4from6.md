## 4/6: Какой из следующих префиксов методов является допустимым для JavaBean?

- of    
- add    
- delete    
- is (выбранный вариант)    
- remove    
- put

---
Правильный ответ: **is** (четвертый вариант).

**Объяснение:**

Согласно спецификации JavaBeans, методы доступа к свойствам (properties) объекта должны использовать определенные префиксы для именования:

1. **Для чтения (геттеры):**
    - **`get`** — для обычных свойств (например, `getName()`, `getAge()`).
    - **`is`** — для логических свойств (тип `boolean`), например, `isActive()`, `isEnabled()`.
2. **Для записи (сеттеры):**
    - **`set`** — для установки значения свойства (например, `setName(String name)`).

Остальные варианты (`of`, `add`, `delete`, `remove`, `put`) не являются стандартными префиксами для свойств JavaBean. Они могут использоваться в обычных методах классов (например, `add()` в коллекциях), но не для доступа к полям через интроспекцию (reflection) в контексте JavaBean.
