## 1/9: Which TWO, inserted independently at line1, will allow the code to compile and produce the output 42?

```java
class H {
    // line1
    protected H(int x) {
        System.out.print(x);
    }
}
class W extends H {
    public static void main(String[] args) {
        W w = new W();
    }
}
```

- protected H() {this(42);}    
- protected H() {super(42);}    
- protected H() {new H(42);}    
- protected H() {H(42);}

---
## 1/9: Какие ДВА варианта, вставленные независимо друг от друга в строку //line1, позволят коду скомпилироваться и вывести 42?

- protected H() {this(42);}    
- protected H() {super(42);}    
- protected H() {new H(42);}    
- protected H() {H(42);}

---
Правильный ответ: **только первый вариант** — `protected H() { this(42); }`

**Объяснение:**

Чтобы код скомпилировался и выдал `42`, нужно решить две проблемы:

1. В классе `W` вызывается конструктор без аргументов (`new W()`), но в классе `W` нет явно объявленного конструктора. Компилятор попытается создать конструктор по умолчанию `W()`, который неявно вызывает `super()` (конструктор родителя без аргументов).
    
2. В классе `H` (родитель) **нет** конструктора без аргументов. Есть только `H(int x)`. Это приведет к ошибке компиляции.
    

Чтобы это исправить, в классе `H` нужно добавить конструктор без аргументов, который вызовет существующий конструктор с параметром. Это делается с помощью ключевого слова **`this(...)`**.

Разберем варианты:

1. **`protected H() { this(42); }` — ВЕРНО.**	    
    - Создается конструктор `H()`, который вызывает другой конструктор этого же класса `H(int x)` с аргументом `42`. Код компилируется, выводится `42`.
    
2. **`protected H() { super(42); }` — НЕВЕРНО.**	    
    - Ключевое слово `super` вызывает конструктор родительского класса. Но класс `H` не наследуется ни от какого явного класса (кроме `Object`), а у `Object` нет конструктора, принимающего `int`.
    
3. **`protected H() { new H(42); }` — НЕВЕРНО (с точки зрения синтаксиса).**
    - Хотя это создаст новый объект (и выведет 42), это неверный синтаксис для цепочки конструкторов. В конструкторе вызов другого конструктора через `new` не инициализирует текущий объект. Кроме того, это вызовет бесконечную рекурсию, если не будет условия выхода.
    
4. **`protected H() { H(42); }` — НЕВЕРНО.**	    
    - Это синтаксическая ошибка. Вызов конструктора как обычного метода невозможен.        

**Примечание:** На скриншоте вопрос просит выбрать ДВА варианта, но корректный синтаксис есть только у одного. Возможно, в тесте подразумевался еще один вариант с использованием `super`, но для текущей иерархии классов он не подходит. Если тест требует именно два ответа, вероятно, в системе закралась ошибка. Но с точки зрения Java, правильный только первый.
