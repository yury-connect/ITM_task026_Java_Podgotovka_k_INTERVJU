```java
System.out.println("" + 2 + 3);
System.out.println(2 + "" + 3);
System.out.println(2 + 3 + "");
System.out.println(2 + 3);
```

- 23, 23, 5, 23    
- 23, 23, 23, 23

## 2/9: Каким будет вывод следующих строк?

- 23, 23, 5, 23    
- 23, 23, 23, 23    
- 5, 23, 5, 5    
- 23, 23, 5, 5    
- 23, 23, 23, 5

---
Правильный ответ: **23, 23, 5, 5** (четвертый вариант).

**Объяснение:**

Этот вопрос проверяет понимание того, как работает оператор `+` (конкатенация строк и сложение) и порядок вычислений (слева направо) в Java.

1. **Строка 1: `System.out.println("" + 2 + 3);`**
    
    - Первым выполняется `"" + 2`. Поскольку первый операнд — строка, число `2` преобразуется в строку. Результат: `"2"`.
        
    - Затем выполняется `"2" + 3`. Число `3` также преобразуется в строку. Результат: **`"23"`**.
        
2. **Строка 2: `System.out.println(2 + "" + 3);`**
    
    - Сначала выполняется `2 + ""`. Один из операндов строка, поэтому число `2` превращается в `"2"`. Результат: `"2"`.
        
    - Затем `"2" + 3` дает строку **`"23"`**.
        
3. **Строка 3: `System.out.println(2 + 3 + "");`**
    
    - Сначала выполняется `2 + 3`. Оба операнда — числа, поэтому происходит **арифметическое сложение**. Результат: `5`.
        
    - Затем выполняется `5 + ""`. Число `5` конкатенируется с пустой строкой и становится строкой. Результат: **`"5"`**.
        
4. **Строка 4: `System.out.println(2 + 3);`**
    
    - Здесь нет строк, только два числа. Выполняется обычное арифметическое сложение. Результат: **`5`**.
        

**Итог:** Программа выведет `23`, `23`, `5` и `5`.
