## 7/9: What will be the result of attempting to compile and run the following code snippet?

```java
int result = 0;
for (int i = 0, j = 0; i < 5 && j < 5; ++i, j = i - 1)
    result += i;
System.out.print(result);
```

- 6    
- 8    
- 9    
- 10    
- Compilation fails

## 7/9: Каким будет результат попытки скомпилировать и выполнить следующий фрагмент кода?

- 6    
- 8    
- 9    
- 10    
- Ошибка компиляции

---
Правильный ответ: **10** (четвертый вариант).

**Пошаговое объяснение:**

Давайте проследим за выполнением цикла. Переменная `i` увеличивается на 1 каждый шаг (`++i`), а `j` вычисляется как `i - 1`. Условие цикла `i < 5 && j < 5`.

- **Итерация 1:**    
    - `i = 0`, `j = 0`.        
    - Условие: `0 < 5 && 0 < 5` (истина).        
    - `result += 0` (result = 0).        
    - Шаг: `i` становится `1`, `j` становится `1 - 1 = 0`.
    
- **Итерация 2:**    
    - `i = 1`, `j = 0`.        
    - Условие: `1 < 5 && 0 < 5` (истина).        
    - `result += 1` (result = 1).        
    - Шаг: `i` становится `2`, `j` становится `2 - 1 = 1`.
    
- **Итерация 3:**    
    - `i = 2`, `j = 1`.        
    - Условие: `2 < 5 && 1 < 5` (истина).        
    - `result += 2` (result = 1 + 2 = 3).        
    - Шаг: `i` становится `3`, `j` становится `3 - 1 = 2`.
    
- **Итерация 4:**    
    - `i = 3`, `j = 2`.        
    - Условие: `3 < 5 && 2 < 5` (истина).        
    - `result += 3` (result = 3 + 3 = 6).        
    - Шаг: `i` становится `4`, `j` становится `4 - 1 = 3`.
    
- **Итерация 5:**    
    - `i = 4`, `j = 3`.        
    - Условие: `4 < 5 && 3 < 5` (истина).        
    - `result += 4` (result = 6 + 4 = 10).        
    - Шаг: `i` становится `5`, `j` становится `5 - 1 = 4`.
    
- **Проверка условия перед следующей итерацией:**    
    - `i = 5`, `j = 4`.        
    - Условие: `5 < 5` (ложь). Цикл завершается.        

**Итог:** Переменная `result` накапливает значения `i`: 0 + 1 + 2 + 3 + 4 = **10**.
