## 19/20: Какой HTTP-метод используется для получения информации с сервера?

- GET    
- DELETE    
- PUT    
- POST

---
Правильный ответ: **GET** (первый вариант).

**Объяснение:**

HTTP-метод **GET** предназначен для запроса данных (получения информации) с сервера. Когда вы вводите адрес сайта в браузере, он отправляет именно GET-запрос для загрузки страницы.

Разберем остальные методы:

- **DELETE** — используется для удаления указанного ресурса на сервере.
    
- **PUT** — используется для полной замены или создания ресурса по указанному URI (в основном для обновления данных).
    
- **POST** — используется для отправки данных на сервер (например, заполненной формы), что часто приводит к созданию нового ресурса или изменению состояния сервера.
