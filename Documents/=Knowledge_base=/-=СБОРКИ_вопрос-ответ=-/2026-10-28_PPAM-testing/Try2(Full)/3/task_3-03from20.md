## 3/20: JUnit is used for what type of software testing for the Java language?

- Functional Testing    
- System Testing    
- Integration Testing    
- Unit Testing    

---
## 3/20: Для какого типа тестирования программного обеспечения на языке Java используется JUnit?

- Функциональное тестирование (Functional Testing)    
- Системное тестирование (System Testing)    
- Интеграционное тестирование (Integration Testing)    
- Модульное тестирование (Unit Testing)

---
Правильный ответ: **Unit Testing** (четвертый вариант).

**Объяснение:**

JUnit — это самый популярный фреймворк для написания и запуска повторяемых тестов в Java. Как следует из его названия (J + Unit), он предназначен в первую очередь для **модульного тестирования** (Unit Testing).

**Что такое модульное тестирование?**  
Это процесс проверки отдельных, изолированных компонентов программы (обычно отдельных методов или классов) на соответствие их ожидаемому поведению. JUnit позволяет разработчикам писать тесты для проверки логики работы конкретных методов, не запуская при этом всё приложение целиком.

#### Остальные варианты не являются основным назначением JUnit:

- **Functional Testing** (Функциональное тестирование) — проверяет, соответствует ли система функциональным требованиям (обычно включает тестирование с точки зрения пользователя).
    
- **System Testing** (Системное тестирование) — тестирование всей системы в целом как единого комплекса.
    
- **Integration Testing** (Интеграционное тестирование) — проверяет взаимодействие между различными модулями или компонентами системы. (Хотя JUnit можно использовать и для интеграционных тестов, его основное призвание — это именно Unit-тесты).
