## 17/20: Which template is a single class that represents an entire subsystem?

- Facade    
- Proxy    
- Singleton    
- Flyweight    

---
## 17/20: Какой паттерн (в тексте использовано слово "template") представляет собой один класс, который олицетворяет целую подсистему?

- Фасад (Facade)    
- Прокси (Proxy)    
- Одиночка (Singleton)    
- Легковес / Приспособленец (Flyweight)

---
Правильный ответ: **Facade** (первый вариант).

**Объяснение:**

Паттерн проектирования **Facade (Фасад)** предоставляет унифицированный (и упрощенный) интерфейс к какой-либо сложной подсистеме.

По сути, класс-фасад является "лицом" целой группы классов. Вместо того чтобы заставлять клиентский код взаимодействовать с десятком различных объектов подсистемы, вы создаете один класс, который скрывает всю эту сложность за собой. Клиент обращается только к фасаду, а фасад уже делегирует вызовы нужным классам подсистемы.

Разберем остальные варианты:

- **Proxy (Заместитель):** Представляет собой суррогат (заместителя) для _одного_ другого объекта, контролируя доступ к нему.
    
- **Singleton (Одиночка):** Гарантирует, что у класса есть только один экземпляр.
    
- **Flyweight (Приспособленец):** Используется для эффективной поддержки множества мелких объектов (экономия памяти за счет разделения общего состояния).
