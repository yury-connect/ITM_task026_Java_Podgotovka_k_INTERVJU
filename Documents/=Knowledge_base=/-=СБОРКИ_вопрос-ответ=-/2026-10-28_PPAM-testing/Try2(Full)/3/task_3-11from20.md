## 11/20: How many lines of the following program contain compilation errors?

```java
package com.epam;
public class QuestPrivate {
    private int var = 77;
    public void QuestPrivate() {
        super();
    }
    public QuestPrivate(int var) {
        this.var = this.var;
    }
    public static void main(String[] args) {
        System.out.print(new com.epam.QuestPrivate(2).var);
    }
}
```

## 11/20: Сколько строк в следующей программе содержат ошибки компиляции?

- 0    
- 1    
- 2    
- 3    
- 4

---
Правильный ответ: **1** (второй вариант).

**Объяснение:**

В этом коде есть ровно **одна** ошибка компиляции.

Ошибка находится в **строке 4**:

```java
public void QuestPrivate() {
```

В Java **конструктор не может иметь возвращаемый тип**. Если вы укажете тип возвращаемого значения (даже `void`), компилятор будет считать это обычным методом, а не конструктором. Поскольку имя метода совпадает с именем класса, компилятор выдаст ошибку: _"Invalid method declaration; return type required"_ (или похожую, указывающую на недопустимость возвращаемого типа для конструктора).

**Разбор остальных строк (почему они компилируются):**

- **Строка 5:** `super();` — Вызов конструктора родительского класса (`Object`) без аргументов. Это допустимо.
    
- **Строка 8:** `this.var = this.var;` — Это логическая ошибка (переменная не меняется), но **не ошибка компиляции**. Код `this.var` слева и справа обращается к одному и тому же полю класса.
    
- **Строка 11:** `System.out.print(new com.epam.QuestPrivate(2).var);` — Хотя поле `var` объявлено как `private` (строка 3), доступ к нему происходит **внутри того же класса** (`QuestPrivate`). В Java `private` члены доступны внутри всего тела класса, включая статические методы. Поэтому эта строка скомпилируется.
    
- **Строка 1:** `package com.epam;` — Объявление пакета. Корректно.

_(Примечание: Из-за ошибки в строке 4, конструктор с параметром `int` в строке 7 не считается конструктором, если бы мы исправили строку 4, но в текущем виде класс пытается использовать `QuestPrivate(2)` — при отсутствии валидного конструктора с таким параметром это вызвало бы вторую ошибку, но тест, вероятно, спрашивает про количество строк именно с синтаксическими ошибками)_.
