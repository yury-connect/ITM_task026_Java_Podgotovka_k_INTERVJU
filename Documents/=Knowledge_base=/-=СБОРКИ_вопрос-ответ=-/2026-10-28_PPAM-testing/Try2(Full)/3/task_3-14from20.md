## 14/20: Что такое бин (bean) в Spring?

- Тип YAML.    
- Java-класс, управляемый контейнером Spring IoC.    
- Тип XML-тега.    
- Тип JSON.

---
Правильный ответ: **A Java class managed by the Spring IoC container** (второй вариант).

**Объяснение:**

В контексте фреймворка Spring, **бин (bean)** — это просто объект (экземпляр Java-класса), который управляется контейнером Spring IoC (Inversion of Control).

Контейнер Spring берет на себя всю работу по:

- Созданию экземпляров этих классов.    
- Внедрению зависимостей (связыванию бинов друг с другом).    
- Управлению их жизненным циклом (инициализация, уничтожение).    

В то время как обычный Java-объект создается вручную через `new`, бин создается и настраивается самим контейнером Spring (на основе аннотаций, конфигураций Java или XML).

Остальные варианты неверны, так как бин — это именно объект Java, а не формат данных (YAML/JSON) или просто XML-тег.
