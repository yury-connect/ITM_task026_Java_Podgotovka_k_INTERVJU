## 20/20: Какие ДВА ключевых слова можно использовать при объявлении конструктора?

---
Правильные ответы (нужно выбрать два):  
**1. private** (третий вариант)  
**2. public** (четвертый вариант)

**Объяснение:**

При объявлении конструктора в Java можно использовать **модификаторы доступа**. Это позволяет контролировать, из каких мест программы можно создавать экземпляры данного класса.

Доступные модификаторы для конструкторов:

1. **`public`** — конструктор доступен из любого места программы (если доступен сам класс).
    
2. **`protected`** — конструктор доступен внутри пакета и в подклассах.
    
3. **`private`** — конструктор доступен только внутри самого класса (часто используется в паттерне "Singleton").
    
4. **Без модификатора (package-private)** — конструктор доступен только внутри того же пакета.    

Разберем остальные варианты из списка:

- `package private` — это не ключевое слово в Java, а описание доступа по умолчанию (когда модификатор не указан). Писать слово "package" перед конструктором нельзя.
    
- `default` — ключевое слово, но оно используется в интерфейсах для методов по умолчанию. Для конструкторов оно не применяется.
    
- `static` — **Конструкторы не могут быть статическими**. Конструктор вызывается для инициализации конкретного экземпляра (объекта), а статические методы принадлежат самому классу, а не объекту. Это приведет к ошибке компиляции.
