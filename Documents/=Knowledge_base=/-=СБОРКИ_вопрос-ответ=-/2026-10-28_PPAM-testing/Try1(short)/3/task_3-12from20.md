## 12/20: Статические методы выполняются без участия какого-либо экземпляра (объекта) класса?

- false (неверно)
    
- true (верно)

---
Правильный ответ: **true** (выбран на скриншоте).

**Объяснение:**

Статические методы (объявленные с ключевым словом `static`) принадлежат самому классу, а не его экземплярам (объектам).

Чтобы вызвать статический метод, вам не нужно создавать объект этого класса через оператор `new`. Вы вызываете его напрямую через имя класса (например, `Math.max(5, 10)` или `Main.main(args)`).

Следовательно, они выполняются без участия какого-либо экземпляра класса.
