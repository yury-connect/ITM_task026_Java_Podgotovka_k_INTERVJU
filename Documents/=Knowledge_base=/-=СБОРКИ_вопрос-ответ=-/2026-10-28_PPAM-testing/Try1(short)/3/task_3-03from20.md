## 3/20: Which TWO of the following method definitions CANNOT be overridden in a subclass?

-  public final void m()
-  public abstract void m()
-  public static void m()
-  protected void m()

---
## 3/20: Какие ДВА из следующих определений методов НЕ МОГУТ быть переопределены (overridden) в подклассе?

- public final void m()
- public abstract void m()
- public static void m()
- protected void m()

---
Правильные ответы (нужно выбрать два):  
**1. `public final void m()`** (первый вариант)  
**2. `public static void m()`** (третий вариант)

**Объяснение:**

В Java есть строгие правила относительно того, какие методы можно переопределять (overriding) в подклассах:

1. **`public final void m()` — НЕЛЬЗЯ переопределить.** Ключевое слово `final` явно запрещает переопределение метода в любых подклассах. Компилятор выдаст ошибку, если вы попытаетесь это сделать.
    
2. **`public static void m()` — НЕЛЬЗЯ переопределить.** Статические методы принадлежат самому классу, а не его экземплярам. В Java статические методы не переопределяются (overridden), а **скрываются** (hidden). Если вы объявите такой же статический метод в подклассе, это не будет полиморфным переопределением.
    
3. **`public abstract void m()` — МОЖНО.** Абстрактные методы _обязаны_ быть переопределены (реализованы) в первом неабстрактном подклассе.
    
4. **`protected void m()` — МОЖНО.** Обычные (не финальные, не статические) методы можно переопределять. Единственное ограничение — нельзя сужать область видимости (например, сделать `private`), но можно расширять (например, сделать `public`).
