## 14/20: Какое регулярное выражение, вставленное в строку line1, правильно разделит строку test на "String A,", "String B," и "String C"?

- `String regex ="\w[\s]+";`
- `String regex =" ";`
- `String regex = ".";`
- `String regex ="\s";`
- `String regex ="\W\s*";`
- `String regex ="";`

---
Правильный ответ: **`String regex = "\\.\\s*";`** (пятый вариант).

**Объяснение:**

Нам нужно разбить строку `"String A. String B. String C."` на три части: `"String A"`, `"String B"` и `"String C"`.  
Глядя на строку, мы видим, что разделителем является **точка с последующим пробелом** (`". "`).

Разберем, как работает регулярное выражение `"\\.\\s*"`:

1. **`\\.`** — это экранированная точка. В регулярных выражениях точка (`.`) означает "любой символ", поэтому, чтобы искать именно точку, перед ней нужно поставить обратный слэш. В строке Java обратный слэш сам по себе требует экранирования, поэтому пишется `\\.`.
2. **`\\s*`** — это ноль или более пробельных символов (`\s` — пробел, `*` — квантификатор "ноль или более раз").

**Почему этот вариант лучше остальных?**  
В строке `"String A. String B. String C."` после точки идет пробел. Регулярное выражение `"\\.\\s*"` найдет точку, а затем "съест" все следующие за ней пробелы (в данном случае один). Это позволит получить чистые строки `"String A"` и `"String B"` без лишних пробелов в начале.

Разберем остальные (неверные) варианты:

- `String regex = "\\w[\\s.]+";` — Слишком сложное и неверное выражение, оно не найдет нужный разделитель корректно.  
    
- `String regex = " ";` — Разобьет строку по пробелам, в результате чего в массиве окажутся слова и точки как отдельные элементы (`"String"`, `"A."`, `"String"`, `"B."` и т.д.).  
    
- `String regex = ".*";` — Это выражение означает "любой символ, повторяющийся любое количество раз". Оно "съест" всю строку целиком, и массив будет пустым.  
    
- `String regex = "\\s*";` — Разобьет строку буквально по каждому символу (так как "ноль или более пробелов" совпадает с пустотой между любыми символами).  
    
- `String regex = "";` — Разобьет строку на отдельные символы.

**Важный нюанс:**  
Если использовать просто `String regex = "\\.";` (только точка), то массив будет содержать `"String A"`, `" String B"` (с пробелом в начале) и `" String C"`. Поэтому вариант с `\\s*` (учитывающий пробелы после точки) является наиболее правильным для получения чистых строк, как требуется в условии.
