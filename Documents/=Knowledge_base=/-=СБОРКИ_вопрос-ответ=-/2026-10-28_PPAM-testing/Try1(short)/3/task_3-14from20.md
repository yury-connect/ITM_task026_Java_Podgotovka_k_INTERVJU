```java
String str = "String A. String B. String C.";
//line1
String[] result = str.split(regex);
```

- `String regex ="\w[\s]+";`    
- `String regex =" ";`    
- `String regex = ".";`    
- `String regex ="\s";`    
- `String regex ="\W\s*";`
