## 16/20: What does the following output?

```java
String[] array = new String[] { "M", "G", "M" };
Arrays.sort(array);
System.out.println(Arrays.binarySearch(array, "M"));
```

- `[0, 2] `   
- `1`    
- `2`    
- `Compilation fails`

## 16/20: Что выводит следующий код?

- `[0, 2]`    
- `1`    
- `2`    
- `Ошибка компиляции`

---
Правильный ответ: **1** (второй вариант).

**Объяснение:**

Давайте разберем код шаг за шагом:

1. **Строка 1:** `String[] array = new String[] { "M", "G", "M" };`  
    Создается массив из трех строк. Изначальный порядок: `["M", "G", "M"]`.
    
2. **Строка 2:** `Arrays.sort(array);`  
    Метод `sort` сортирует массив в естественном (алфавитном) порядке. После сортировки массив выглядит так: **`["G", "M", "M"]`** (индексы 0, 1 и 2 соответственно).
    
3. **Строка 3:** `System.out.println(Arrays.binarySearch(array, "M"));`  
    Метод `binarySearch` ищет указанное значение (в данном случае `"M"`) в **отсортированном** массиве, используя алгоритм бинарного поиска (деление массива пополам).

**Как работает бинарный поиск в данном случае:**

- Массив: `["G", "M", "M"]`. Ищем `"M"`.
    
- Шаг 1: Берется средний элемент. Индекс середины = `(0 + 2) / 2 = 1`. Элемент под индексом 1 — это `"M"`.
    
- Сравниваем искомый `"M"` с найденным `"M"`. Они совпадают. Поиск успешно завершается.

Метод возвращает **индекс найденного элемента**. Так как он нашел `"M"` под индексом `1`, он возвращает **`1`**.

_(Примечание: Если в массиве несколько одинаковых элементов, метод `binarySearch` не гарантирует, что вернется индекс первого из них. Он вернет индекс любого найденного элемента, в зависимости от того, на какую половину он попадет в процессе деления. В данном случае он попал ровно в середину)._
