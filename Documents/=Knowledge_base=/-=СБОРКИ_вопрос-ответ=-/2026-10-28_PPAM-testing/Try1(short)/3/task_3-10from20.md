## 10/20: Какой из этих классов является суперклассом (родительским классом) для каждого класса в Java?

- Constructor    
- Method    
- Object    
- Class

---
Правильный ответ: **Object** (третий вариант).

**Объяснение:**

В Java класс `java.lang.Object` является корнем иерархии классов. Это означает, что **каждый** класс в Java неявно наследуется от класса `Object` (если только он явно не наследуется от другого класса, который, в свою очередь, в конечном итоге наследуется от `Object`).

Даже если вы не пишете `extends Object`, компилятор добавляет это автоматически.

Остальные варианты не являются классами-предками для всех классов:
- `Constructor` — класс, представляющий конструктор (сам наследуется от `Object`).    
- `Method` — класс, представляющий метод (также наследуется от `Object`).    
- `Class` — класс, представляющий классы во время выполнения (метаданные), но он сам является наследником `Object`, а не предком.
