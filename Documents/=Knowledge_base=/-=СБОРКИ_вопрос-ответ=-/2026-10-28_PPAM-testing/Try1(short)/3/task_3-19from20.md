## 19/20: What is the output of the below program?

```java
try {
    int x, sum;
    sum = 10;
    for (x = -1; x < 3; ++x) {
        sum = (sum / x);
        System.out.print(x);
    }
} catch (ArithmeticException e) {
    System.out.print("0");
}
```

- -1    
- -101    
- -10    
- 0    
- Compilation fails

## 19/20: Каков вывод приведенной ниже программы?

- -1    
- -101    
- -10    
- 0    
- Ошибка компиляции

---
Правильный ответ: **-10** (третий вариант).

**Пошаговое объяснение:**

1. **Инициализация:** `sum = 10`. Цикл начинается с `x = -1`.
    
2. **Итерация 1 (`x = -1`):**	    
    - `sum = (10 / -1)` -> `sum = -10`.        
    - `System.out.print(x)` выводит **`-1`**.        
    - `++x` увеличивает `x` до `0`.
    
3. **Итерация 2 (`x = 0`):**	    
    - Условие цикла `x < 3` (0 < 3) истинно.        
    - Выполняется `sum = (sum / x)` -> `-10 / 0`.        
    - Деление на ноль вызывает исключение **`ArithmeticException`**.
    
4. **Обработка исключения:**	    
    - Управление передается в блок `catch`.        
    - Выполняется `System.out.print("0")`.        
    - (Примечание: строка `System.out.print(x)` внутри цикла для `x=0` **не выполняется**, так как исключение прерывает выполнение блока `try` до этого момента).

**Итог:** Программа сначала выведет `-1`, затем перехватит исключение и выведет `0`. Вместе это дает **`-10`**.
