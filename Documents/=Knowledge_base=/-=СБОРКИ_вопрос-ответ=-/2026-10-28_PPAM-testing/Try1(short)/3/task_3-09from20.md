## 9/20: What will the following code will print when compiled and run?

```java
interface I {
    int i = 10; //line1
}
public class C implements I {
    public static void main(String[] args) {
        for ( ; i < 5; i++) //line2
            System.out.print(i); //line3
    }
}
```

- Compilation fails at line1.    
- Compilation fails at line2.    
- Compilation fails at line3.    
- No output.    
- An exception is thrown at runtime.

## 9/20: Что выведет следующий код при компиляции и запуске?

- Ошибка компиляции в строке 1 (line1).    
- Ошибка компиляции в строке 2 (line2).    
- Ошибка компиляции в строке 3 (line3).    
- Нет вывода (No output).    
- Во время выполнения будет выброшено исключение.

---
Правильный ответ: **Compilation fails at line2** (Компиляция завершится с ошибкой во второй строке).

**Объяснение:**

Ошибка возникает в **строке 6**: `for ( ; i < 5; i++)`

Вот почему это происходит:

1. В интерфейсе `I` объявлена переменная: `int i = 10;` (строка 2).
    
2. **Все поля в интерфейсах Java по умолчанию являются `public static final`**. Это означает, что переменная `i` — это **константа**, и её значение нельзя изменить после инициализации.
    
3. В строке 6 в цикле `for` происходит попытка инкремента: `i++`. Это эквивалентно `i = i + 1`.
    
4. Поскольку `i` является `final`, компилятор запрещает любые попытки присвоить ей новое значение. Он выдаст ошибку: `cannot assign a value to final variable i`.

**Почему не другие строки?**

- **Строка 1 (`int i = 10;`):** В интерфейсе переменные неявно `public static final int i = 10;`. Это допустимо и успешно компилируется (инициализация константы).
    
- **Строка 3 (`System.out.print(i);`):** Класс `C` реализует интерфейс `I`. Он имеет доступ к константе `i` (через неявное наследование статических полей). Чтение значения константы разрешено.
    
- Если бы код скомпилировался (без `i++`), то `i` всегда было бы равно 10, условие `10 < 5` было бы ложным, и программа вывела бы **No output** (ничего), так как тело цикла ни разу не выполнилось бы. Но из-за попытки изменить `final`-переменную код не скомпилируется.
