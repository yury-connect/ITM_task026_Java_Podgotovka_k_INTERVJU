## 2/9: Какой из этих классов является суперклассом (родительским классом) для класса Exception?

- ExceptionLoader    
- System    
- Class    
- Throwable

---
Правильный ответ: **Throwable** (четвертый вариант).

**Объяснение:**

В иерархии классов Java класс `Exception` является наследником класса `Throwable`.

Схема наследования выглядит так:

- `java.lang.Object`
    - `java.lang.Throwable` (корневой класс для всех ошибок и исключений)
        - `java.lang.Exception` (класс, от которого наследуются большинство исключений)
            - `java.lang.RuntimeException` (исключения времени выполнения) и другие проверяемые исключения.
        - `java.lang.Error` (серьезные ошибки, которые не следует перехватывать)

Остальные варианты не имеют отношения к иерархии исключений:

- `ExceptionLoader` — такого класса в стандартной библиотеке Java нет (есть `ClassLoader`, но он загружает классы).  
    
- `System` — класс для доступа к системным ресурсам.  
    
- `Class` — класс, представляющий классы и интерфейсы во время выполнения.
