## 9/9: Which of the following methods cause the String object referenced by s to be changed?

- None of these    
- format()    
- trim()    
- toUpperCase()    

---
## 9/9: Какой из следующих методов приводит к изменению объекта String, на который ссылается переменная s?

- Ни один из этих (None of these)    
- format()    
- trim()    
- toUpperCase()

---
Правильный ответ: **None of these** (Ни один из них).

**Объяснение:**

Класс `String` в Java является **неизменяемым (immutable)**. Это означает, что после создания объекта `String` его содержимое нельзя изменить.

Все методы, перечисленные в вариантах (`format()`, `trim()`, `toUpperCase()`), не изменяют исходный объект. Вместо этого они **возвращают новый объект** `String`, содержащий результат операции, оставляя исходную строку `s` без изменений.

Например:
```java
String s = " hello ";
s.trim(); // Возвращает новую строку "hello", но s остается " hello "
s = s.trim(); // Вот так можно изменить ссылку, но сам объект " hello " остался неизменным
```

- `format()` — статический метод класса `String`, возвращает новую отформатированную строку.
    
- `trim()` — возвращает копию строки с удаленными пробелами в начале и конце.
    
- `toUpperCase()` — возвращает копию строки в верхнем регистре.    

Поскольку ни один из этих методов не может изменить исходный объект, правильный ответ — **None of these**.
