## 8/9: What will be the result of following code fragment?

```java
public static void main(String[] args) {
    for (int i = 0; i <= 10; i++) {
        if (i > 6) break;
    }
    System.out.println(i);
}
```

- 6    
- Compilation fails    
- An exception at thrown on runtime    
- 7

## 8/9: Каким будет результат следующего фрагмента кода?

- 6    
- Ошибка компиляции    
- Во время выполнения будет выброшено исключение    
- 7

---
Правильный ответ: **Compilation fails** (Компиляция завершится с ошибкой).

**Объяснение:**

Ошибка возникает из-за **области видимости переменной**.

1. Переменная `i` объявлена внутри цикла `for` в круглых скобках: `for (int i = 0; ...)`.
    
2. В Java переменная, объявленная в заголовке цикла `for`, имеет область видимости (scope) **только внутри тела этого цикла**.
    
3. В строке 5 происходит попытка вывести переменную `i` (`System.out.println(i);`), но эта строка находится **вне цикла**. Для компилятора переменная `i` здесь не существует, поэтому он выдаст ошибку: `cannot find symbol variable i`.

**Важное дополнение (если бы код компилировался):**  
Даже если бы переменная `i` была объявлена до цикла (например, `int i;` перед циклом), код вывел бы **`7`**.  
Это происходит потому, что цикл прерывается (`break`) на значении `7` (так как условие `7 > 6` истинно), и именно это значение сохраняется в переменной `i` к моменту выхода из цикла. Но из-за ошибки области видимости программа не запустится.
