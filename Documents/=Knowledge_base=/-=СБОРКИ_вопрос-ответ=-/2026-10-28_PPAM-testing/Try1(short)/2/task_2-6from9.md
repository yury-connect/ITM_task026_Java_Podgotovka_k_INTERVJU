```java
int num = 4;
float flo = 4.3f;
double doub = 1.8;
int count = 0;

if (((int) (flo + doub)) == ((int) flo + (int) doub)) count += 2;
System.out.println(count);
```

- 0

## 6/9: Каким будет результат попытки скомпилировать и выполнить следующий код?

- 0    
- 1    
- 2    
- 3    
- Ошибка компиляции

---
Правильный ответ: **1** (второй вариант).

**Объяснение:**

Давайте разберем код по шагам:

1. **Строки 1-4:** Инициализация переменных.    
    - `num = 4`        
    - `flo = 4.3f`        
    - `doub = 1.8`        
    - `count = 0`
    
2. **Строка 5:** `if (num == (int) flo) count++;`    
    - При приведении типа `(int) flo` дробная часть отбрасывается. `4.3f` превращается в `4`.        
    - Условие: `4 == 4` — это **истина** (`true`).        
    - Выполняется `count++`. Теперь `count = 1`.
    
3. **Строка 6:** `if (((int) (flo + doub)) == ((int) flo + (int) doub)) count += 2;`    
    - Сначала вычисляется левая часть: `flo + doub` = `4.3 + 1.8` = `6.1`. При приведении к `int` получаем **`6`**.        
    - Затем вычисляется правая часть: `(int) flo` = `4`, `(int) doub` = `1`. Складываем: `4 + 1` = **`5`**.        
    - Сравниваем: `6 == 5` — это **ложь** (`false`).        
    - Блок `if` не выполняется, `count` не увеличивается. `count` остается равен `1`.
    
4. **Строка 7:** `System.out.println(count);`    
    - Выводит текущее значение `count`, то есть **`1`**.        

**Итог:** Программа успешно скомпилируется и выведет `1`. Уловка задачи заключается в разнице между приведением типа _после_ сложения (в левой части) и _до_ сложения (в правой части).
