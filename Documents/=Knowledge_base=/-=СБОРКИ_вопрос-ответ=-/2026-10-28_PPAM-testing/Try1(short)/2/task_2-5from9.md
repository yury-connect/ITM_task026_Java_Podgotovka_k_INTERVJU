## 5/9: Какие ДВА описания массива скомпилируются для данного объявления массива?

- `multiArr = new int[][3]`;
- `multiArr = new int[]`;
- `multiArr = new int[3][3]`;
- `multiArr = new int[3][]`;

---
Правильные ответы (нужно выбрать два):  
**1. `multiArr = new int[3][];`** (четвертый вариант)  
**2. `multiArr = new int[3][3];`** (третий вариант)

**Объяснение:**

В строке 1 объявлен двумерный массив: `int[] multiArr[];` (это эквивалентно `int[][] multiArr;`).  
При инициализации двумерного массива в Java **обязательно указывать размер первого (внешнего) измерения**. Размер второго (внутреннего) измерения указывать необязательно.

Разберем каждый вариант:

1. `multiArr = new int[][3];` — **Ошибка компиляции**. Нельзя указывать размер второго измерения, не указав размер первого.
    
2. `multiArr = new int[];` — **Ошибка компиляции**. Синтаксическая ошибка, размер массива не указан вообще (пустые скобки недопустимы при создании массива через `new`).
    
3. `multiArr = new int[3][3];` — **Верно**. Создается прямоугольный массив 3x3. Указаны размеры обоих измерений.
    
4. `multiArr = new int[3][];` — **Верно**. Создается массив, состоящий из 3 элементов. Каждый элемент — это ссылка на массив типа `int[]`, которая по умолчанию равна `null`. Внутренние массивы можно будет инициализировать позже (например, `multiArr[0] = new int[5];`).
