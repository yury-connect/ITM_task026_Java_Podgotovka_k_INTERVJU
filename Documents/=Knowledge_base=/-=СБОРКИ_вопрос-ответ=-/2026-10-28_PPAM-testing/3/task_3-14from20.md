## 14/20: What is a bean in Spring?

- A type of YAML.    
- A Java class managed by the Spring IoC container.    
- A type of XML tag.    
- A type of JSON.

## 14/20: Что такое бин (bean) в Spring?

- Тип YAML.    
- Java-класс, управляемый контейнером Spring IoC.    
- Тип XML-тега.    
- Тип JSON.
