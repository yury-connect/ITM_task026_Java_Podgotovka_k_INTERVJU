### 1. Интервейл (Intervale / ООО «Интервэйл-Гомель»)

- **Почему топ**: Недавние вакансии Java-разработчика (в т.ч. без опыта / junior-level, Spring Boot приветствуется, SQL, SOAP/JSON, Liquibase, Git/Maven/Jira). Fintech (платежи, электронная/мобильная коммерция, банковские решения). Собственный офис в Гомеле, подтверждённый Java-стек (Java 8+, Spring, JPA/Hibernate и др.). Регулярно публикует позиции.
- Высокая вероятность найма, особенно junior/middle.

### 2. Team.Inno / Innowise Group (Фабрика инноваций и решений)

- **Почему высоко**: Вакансии Java Developer (в т.ч. 3–6 лет опыта, Java/Kotlin, Spring Boot/Data/Cloud, микросервисы, Kafka/RabbitMQ, Docker/K8s, SQL/NoSQL, английский/немецкий B2). Крупная белорусская аутсорс-компания с проектами полного цикла, офисы в Беларуси (включая Гомель). Активно ищет специалистов.
- Хорошая вероятность для middle+.

### 3. РИНАР (ООО «РИНАР-Автоматика»)

- **Почему высоко**: Вакансии Java-разработчика (опыт от 1–2/3 лет, Spring Framework/Boot, PostgreSQL, REST, Maven, RabbitMQ, Hibernate). Автоматизация промышленных процессов, АСУ. Недавние публикации.
- Релевантно для тех, кто готов к промышленной/enterprise-тематике.

### 4. SENLA (СЕНЛА / SENLA Group)

- **Почему высоко**: Вакансии Junior Java Developer / Java Software Engineer в Гомеле (Java Core 8/11+, Spring ecosystem, J2EE-компоненты). Присутствие в Гомеле (и других городах), специализация на Java, fintech, medicine и др. enterprise-решения. Упоминания Senior Java из Гомеля на местных IT-мероприятиях.
- Хорошие шансы для junior/middle, особенно с коммерческим опытом.

### 5. Производственное объединение «Белоруснефть» (IT-подразделение)

- **Почему релевантно**: Недавняя вакансия Middle Java-разработчик (Java 11/17+, Spring Boot, микросервисы, REST API, PostgreSQL/MySQL/MongoDB, Kafka/RabbitMQ, Docker/K8s и др.). Работа в офисе в Гомеле или Минске.
- Вероятность есть, но позиции могут быть реже и более «корпоративные».

### 6. IBA Gomel / IBA Group (ИВА-Гомель-Парк / IBA Gomel Park)

- **Почему релевантно**: Крупный центр разработки в Гомеле (сотни специалистов, резидент ПВТ), исторически и по направлениям — Java/J2EE, web, enterprise, SAP, BI и др. Системная интеграция и аутсорс. Большой штат повышает вероятность периодических открытий.
- Стабильный работодатель; следите за вакансиями на корпоративных каналах.

### 7–8. Andersen и Aston

- **Andersen**: Регулярные стажировки/trainee Java (с последующим трудоустройством, офис/remote включая Гомель), плюс QA Automation (Java). Аутсорс, быстрый рост.
- **Aston**: Присутствие в Гомеле, стажировки/ученики Java и связанные позиции (в т.ч. тестирование Java).
- Хороший вход для начинающих через trainee-программы.

### 9–10. EPAM Systems и iTechArt Group

- **EPAM**: Исторически офис/присутствие в Гомеле, огромный объём Java-разработки глобально. Найм в Беларуси в последние годы ограничен/волнообразный, но remote/гибрид и локальные позиции периодически появляются.
- **iTechArt**: Присутствие и лаборатории/сотрудничество в Гомеле (с университетами), разработка ПО. Java встречается в стеке компании.
- Вероятность ниже текущих топ-позиций из-за общей динамики рынка, но компании крупные.

### Рекомендации по поиску

- Основные источники: **rabota.by** (gomel.rabota.by), **HH.ru** (фильтр Гомель + Java), dreamjob.ru, корпоративные сайты компаний, LinkedIn, местные IT-сообщества/конференция OPEN IT GOMEL.
- Вакансии часто архивируются быстро; проверяйте «активные» и откликайтесь сразу. Многие принимают удалёнку/гибрид.
- Рынок динамичный: даже при отсутствии открытой вакансии имеет смысл отправлять резюме (особенно middle+ с Spring/микросервисами/английским) — компании держат «кадровый резерв».
- Дополнительно: университетские партнёрства (ГГУ им. Скорины и др.) и стажировки повышают шансы для junior.
