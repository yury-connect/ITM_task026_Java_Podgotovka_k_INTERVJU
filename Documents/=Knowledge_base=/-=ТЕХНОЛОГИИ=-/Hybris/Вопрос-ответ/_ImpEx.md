**ImpEx (Import/Export)** — это текстовый инструмент и CSV-подобный язык скриптов в SAP Commerce Cloud (Hybris), предназначенный для импорта, обновления, экспорта и удаления данных в базе данных платформы.

### Для чего используется ImpEx

- **Загрузка каталогов:** Наполнение базы товарами, категориями, ценами, складами и медиа-файлами.
    
- **Конфигурация CMS:** Создание и разметка страниц, слотов и компонентов.
    
- **Миграция данных:** Перенос настроек, прав пользователей и контента между окружениями (`DEV` $\rightarrow$ `TEST` $\rightarrow$ `STAGE` $\rightarrow$ `PROD`).
    
- **Коррекция данных:** Быстрый накат фиксов и обновление статусов без написания Java-кода.    

### Структура ImpEx-скрипта

Скрипт состоит из трех основных элементов: **макросов**, **заголовка (Header)** и **строк данных (Value Lines)**.

Фрагмент кода
```
# 1. МАКРОСЫ (переменные для сокращения повторяющегося кода)
$productCatalog=myCatalog
$catalogVersion=catalogVersion(catalog(id[default=$productCatalog]), version[default='Staged'])
$approved=approvalStatus(code[default='approved'])

# 2. ЗАГОЛОВОК (Операция, Тип сущности и Атрибуты)
INSERT_UPDATE Product; code[unique=true]; name[lang=ru]; name[lang=en]; $catalogVersion[unique=true]; $approved; unit(code)

# 3. СТРОКИ ДАННЫХ (разделитель — точка с запятой ;)
; prod_1001 ; Кофемашина ; Coffee Maker ; ; ; pieces
; prod_1002 ; Чайник     ; Kettle       ; ; ; pieces
```

### Основные директивы (Операции)

|**Директива**|**Назначение**|**Поведение при наличии записи в БД**|
|---|---|---|
|**`INSERT`**|Создание новой записи|Выбрасывает ошибку, если запись с таким `[unique=true]` уже есть.|
|**`UPDATE`**|Обновление существующей|Игнорирует строку, если запись с таким `[unique=true]` не найдена.|
|**`INSERT_UPDATE`**|Создание или обновление (Upsert)|Создает новую запись, если её нет, или обновляет существующую.|
|**`REMOVE`**|Удаление записи|Физически удаляет из БД запись, найденную по `[unique=true]`.|

### Ключевые модификаторы атрибутов

В заголовке таблицы после имени поля в квадратных скобках указываются правила обработки:

- **`[unique=true]`** — задает поле (или комбинацию полей) как уникальный ключ для поиска существующей записи в БД.
    
- **`[lang=ru]`** — указывает язык для мультиязычных (localized) атрибутов.
    
- **`[default=value]`** — задает дефолтное значение, если ячейка в строке данных пустая.
    
- **`[translator=...]`** — подключает кастомный Java-класс для трансформации значения прямо во время импорта (например, конвертация даты или обработка медиа-файлов).
    
- **`[dateformat=yyyy-MM-dd]`** — определяет формат парсинга дат.    

### Важные технические нюансы

1. **Enable Code Execution:** Опция импорта, позволяющая выполнять скрипты на **Groovy** или **BeanShell** прямо внутри CSV-строк (например, для динамического хеширования или сложных вычислений):
    
    Фрагмент кода
```sql
INSERT_UPDATE Customer; uid[unique=true]; customerID
#% code: "user_" + line.get(1)
; john@example.com ; #% code
```
    
2. **Импорт медиа:** Загружает физические файлы картинки из ZIP-архива в Media Storage с помощью специального транслятора:
    
    Фрагмент кода
```sql
$importFolder=jar:de.hybris.platform.impex.jalo.ImpExManager
INSERT_UPDATE Media; code[unique=true]; @media[translator=de.hybris.platform.impex.jalo.media.MediaDataTranslator]
; banner_01.jpg ; /images/banner_01.jpg
```
    
3. **Enable Legacy Mode:** Переключает движок с modern `ServiceLayer` (с вызовом интерцепторов `Prepare`/`Validate`) на унаследованный `JALO Layer` (запись напрямую в БД без проверок бизнес-правил, используется для максимального ускорения загрузки гигантских объемов).
