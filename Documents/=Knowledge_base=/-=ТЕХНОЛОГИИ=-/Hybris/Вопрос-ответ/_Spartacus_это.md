**Spartacus** (официальное современное название — **SAP Commerce Composable Storefront**) — это готовый открытый (open-source) JavaScript-фронтенд для витрин интернет-магазинов, разработанный компанией SAP специально для платформы SAP Commerce Cloud (Hybris).

Оно создано для реализации **Headless-архитектуры**: фронтенд полностью отрезан от тяжелого бэкенда Hybris и общается с ним исключительно через REST API (**OCC — Omni Commerce Connect**).

### Ключевые особенности и стек

- **Технологический стек:** Построен на базе **Angular** и **TypeScript**. Работает как Single Page Application (SPA) и поддерживает возможности Progressive Web App (PWA).
    
- **Server-Side Rendering (SSR):** Для высокой скорости первой загрузки и полноценного SEO-продвижения использует рендеринг страниц на стороне сервера с помощью **Node.js**.
    
- **Обновляемость (Upgradability):** Код Spartacus поставляется в виде подключаемых npm-библиотек. Кастомизация пишется поверх них без изменения ядра, что позволяет обновлять версию витрины без переписывания всего кода проекта.
    
- **Модульность:** Состоит из изолированных плагинов и библиотек. Можно подключать только те модули, которые необходимы бизнесу (например, модуль B2B-чекаута или B2C-каталога).
    

### Зачем нужен Spartacus?

В старых версиях Hybris витрина создавалась на базе **Accelerator (JSP/JSTL)**, где HTML-страницы рендерились напрямую бэкендом. Это затрудняло разработку, замедляло сайт и требовало от Java-разработчиков глубоких знаний верстки.

**Spartacus решает эти проблемы:**

1. **Разделение команд:** Фронтендеры пишут на стандартном Angular и не заходят в Java-код, а бэкендеры занимаются только бизнес-логикой и API.
    
2. **Скорость витрины:** Сайт загружается динамически, а страницы переключаются без полной перезагрузки браузера.
    
3. **Мультиканальность:** Используя то же самое OCC API, компания может быстро запустить мобильное приложение или кассовый терминал параллельно со Spartacus.
