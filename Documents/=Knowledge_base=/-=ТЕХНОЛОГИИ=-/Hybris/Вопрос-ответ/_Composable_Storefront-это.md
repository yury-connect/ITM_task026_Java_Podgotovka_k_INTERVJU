**SAP Commerce Composable Storefront** — это официальное современное название фреймворка **Spartacus**. Это готовый открытый (open-source) JavaScript-фронтенд от компании SAP, созданный на базе **Angular** и **Node.js** для построения витрин интернет-магазинов по принципам Headless-архитектуры.

### Почему именно "Composable"?

Термин происходит от концепции **Composable Commerce** (собираемая коммерция). В отличие от старых монолитных систем, где витрина зашита в код платформы, Composable-подход предлагает собирать витрину из независимых, легко заменяемых кубиков (модулей) по стандарту MACH (Microservices, API-first, Cloud-native, Headless).

В Composable Storefront вся витрина разбита на отдельные **NPM-пакеты** (`@spartacus/core`, `@spartacus/storefront`, `@spartacus/checkout`, `@spartacus/b2b` и т.д.). Вы можете подключить только нужные модули и настраивать их независимо.

### Сравнение: Классический Accelerator vs Composable Storefront

|**Параметр**|**SAP Accelerator (Legacy)**|**Composable Storefront (Spartacus)**|
|---|---|---|
|**Архитектура**|Монолит (JSP/JSTL)|Headless (Angular SPA + Node.js SSR)|
|**Связь с Hybris**|Прямая (HTML рендерится в Java-коде)|Отдельная (только через OCC REST API)|
|**Обновляемость**|Сложная (кастомный код переписывает ядро)|Простая (обновление через NPM-зависимости)|
|**Разработка**|Java-разработчик должен верстать JSP|Четкое разделение: Java (Backend) и Angular (Frontend)|
|**Скорость работы**|Перезагрузка страницы при каждом клике|Моментальная смена страниц без перезагрузки (SPA)|

### Как это устроено технически

1. **Angular (Клиентская часть):** В браузере покупателя работает динамическое приложение (Single Page Application). Оно запрашивает данные у Hybris по защищенным REST-эндпоинтам (OCC API) и отрисовывает UI.
    
2. **Node.js / Express (SSR Server):** Серверный слой, который перехватывает первичный запрос от пользователя или поискового бота (Google, Yandex), запрашивает JSON у Hybris, собирает готовый HTML и моментально отдаёт его в браузер. Это гарантирует высокое SEO и быстрый показ страницы.
    
3. **SmartEdit Integration:** Поддерживает визуальное редактирование страниц прямо из админки Hybris. Контент-менеджеры могут менять блоки, баннеры и слоты на витрине Composable Storefront в режиме Drag-and-Drop.
    

### Главные преимущества для бизнеса и команды

- **Бесшовные обновления (Upgradability):** Это главное преимущество. Поскольку код Composable Storefront подключается как внешние библиотеки, при выходе новой версии от SAP вы просто обновляете версии в `package.json`. Кастомная бизнес-логика проекта при этом не ломается.
    
- **Готовые B2C и B2B сценарии:** Из коробки доступны преднастроенные модули для B2C (корзина, чекаут, отзывы, фасетный поиск) и B2B (древо организации `B2BUnit`, согласование смет, быстрые заказы по CSV, спец. цены).
    
- **PWA (Progressive Web App):** Витрину можно в один клик «установить» на смартфон пользователя как мобильное приложение с поддержкой push-уведомлений и частичной работой оффлайн.
